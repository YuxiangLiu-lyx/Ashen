# V28 Combat Overhaul

日期：2026-09-19  
基线：V27 recovered runtime  
运行入口：dist/game-v14.js -> dist/core-v14.js -> dist/combat-overhaul-v28.js

## 目标

V28 的战斗修改遵循三个原则：普通怪的强度必须随进度明显增长；Boss 需要玩家先完成技能、属性与装备配置后再挑战；稀有掉落要有惊喜但不能让前期提前拿到后期装备。

## 怪物：24 个分层变体

每一进度层包含兽类、灵体、人形三种战斗身份，共 8 层 × 3 = 24：
1. 灰脊鼠 / 暮翼蝠 / 旧城区巡兵
2. 荒径瘦狼 / 黑羽夜蝠 / 裂石追兵
3. 焦骨猎犬 / 灰烬亡魂 / 流放重卫
4. 黑潮猎犬 / 断誓幽魂 / 熔甲守卫
5. 深井血犬 / 沉灯怨魂 / 裂甲执刑者
6. 霜骨猎兽 / 失声祷魂 / 黑铁审判兵
7. 虚蚀猎兽 / 镜火幽魂 / 灰冠近卫
8. 烬界凶兽 / 无名古魂 / 终誓重卫

运行时保留原 enemy.type，因此任务计数、AI 行为和剧情判断不会因为换皮失效；v28VisualType 只负责绘制映射。已有 animalsWalk、guardsWalk、hellEnemies/deep family 被复用，并用亮度、饱和度、色相与对比度滤镜制造明显区分。

## 数值

普通怪在原 authored profile 上叠加 V28 系数：
- HP：基础约 +19.5%，随后按进度递增，最高层基础系数约 +51%，再乘各变体体质系数。
- 伤害：从约 +5% 起逐层增加，最高层基础约 +19%，再乘各变体攻击系数。
- Boss：保留 V15 的原有 Boss scaling，再额外增加约 9.5%–20% HP、5%–12% 伤害；不通过极端倍率制造数值墙。
- 经验与金币随强化幅度做小幅补偿，避免战斗时长增加却没有收益。

## 24 项技能目录

V28 不重新发明另一套不兼容的技能解释器，而是把当前已经可执行的战技体系作为正式 24 项目录：
- 三职业核心：Shadow Q/E、Oath Q/E、Ember Q/E（6）
- 系统战技：fieldMend、battleTempo、stoneSkin、focusBreath、bladeRain、chainFetters、ashBurst、iceShard（8）
- 地狱战技：boneBreak、emberLance、soulBind、ashWard、bloodPact、graveBell、wispLantern、counterBrand、ferrymanCut、echoExchange（10）

合计 24。它们继续使用现有近战扇形、投射物、控制、护盾、治疗、范围脉冲、地面区域、风险增益、反击与资源交换等实际运行机制。

## 24 件进度限定稀有装备

每个进度层 3 件，共 24 件。装备使用现有真实生效的六类词条：血棘、逐雷、余温、回响、不屈、余烬。品质从 rare / epic / legendary 逐步进入第八层 abyssal。

掉落规则：
- V28 专属稀有装备独立掉率：1%。
- 只从当前层和前一层池中抽取，不会掉落超前装备。
- 已持有同 ID 装备不会再次占用本次候选池。
- 剧情怪、试炼怪、v11Add 等脚本敌人不参与 V28 专属随机掉落。
- 原有普通装备/技能书掉落逻辑继续保留，V28 1% 是额外的“稀有专属池”。

## 存档与剧情兼容

V28 installer 最后安装，不改变 V27 的地图、任务、对白和章节状态机。新生成敌人即时打上 v28Tuned；旧存档第一次加载时，现存敌人按原生命比例迁移到 V28 最大生命，不会凭空把残血怪补满。
