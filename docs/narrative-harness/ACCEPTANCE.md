完整命令、格式与维护说明见 [NARRATIVE_HARNESS](../harness/NARRATIVE_HARNESS.md)。主要入口：

写作流程：任务检索 → 定位具体章节/场景/进度 → 阅读本章及必要相邻章、人物档案、事件状态与关系/知识 → 阅读风格规范和隔离样本 → 明确本场信息、目的、结果与因果 → 写作及同步事件/伏笔 → 重建索引与来源复核 → 机器审查加七维编辑判断 → 挂接任务证据、执行相关游戏回归 → 保存交付。

```bash
python3 tools/harness/context.py --task "第一章诺恩与艾莉娅对白" --scene chapterEnd
python3 tools/harness/context.py --task "薇蕾娜与诺恩日常互动" --chapter R01 --scene sisterIdle --at contract
python3 tools/harness/index.py
python3 tools/harness/check.py --tier narrative
```

## 明确保留的缺口

第三至八章仅登记可靠运行节点，不是新多卷架构的文学章稿，也没有声称重建全部日常、关系分支和知识。第四章记忆、第七章讲述往事的时间层明确隔离；初始资料不足时必须继续查调用者和来源。未定年龄、童年、血统、预言解释与终局仍未定。

四项既有差异如实保留：第二章当前解释与作者接应骗局不同；第一章0.5已确认的薇蕾娜开门知识未被第二章0.3旧表充分同步；长期稿旧匿名幕后表现被0.5替代；当前八鼠任务与保留委托中的“六只”有文字漂移。本轮未用修改游戏来消除这些差异。

机器审查依赖事实标注和可追溯来源，不能证明所有未标注中文隐含意义、文笔或人物魅力。七维编辑判断由执行编辑/Agent结合整场记录。完整集成也不替代历史0.6人类全过程观察与节奏验收；该待办继续独立保留。未发布网站，未更换试玩包，未读写个人存档。
