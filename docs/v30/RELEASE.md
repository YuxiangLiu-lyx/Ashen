基线：`e77f6d71413d8f6cd6c2e34bcfa7c305df89826d`，继承V29探索规则及V28.1人物/碰撞修复。运行入口仍为`dist/`。本轮按用户要求先诊断、再实施；[问题与修改方向](REVIEW_AND_PLAN.md)、[11图滑动对照](visual-review.html)。

## 实际改动

- 覆盖会馆、库房、旧王道、白榆城、礼拜厅、后巷、水渠、林地、磨坊小径、回水机房、修理铺，共11图。新增4张环境图集，统一木石材质、旧建筑、货物、摊位、祭台与机房设备；增加接地阴影、局部光线、落叶、水波和轻微树冠运动。
- 按用途替换物件：库房书架改货箱/麻袋，调查墙板、灯油、邮袋、检修簿、阀门及机芯使用对应实物。靠近才显示场景入口和交互文字，减少常驻环形/菱形标记。
- 取消V29计时操作和转圈：验证距离、视线及任务条件后立即执行，反馈不锁移动/保存；保留清场、调查、一次性领取与旧档迁移。客房原有同机制交互也即时执行。
- 第一章怪物不再绘制附加骨脊、羽冠等几何装饰。守卫新增16帧正反方向行走/蓄势/出手/收势图集，战斗和剧情使用同一套脚底锚点；主角与动物补身体蓄势、受击、倒地反馈，普通攻击收敛为短刀光。
- 沿用任务状态保留开阀蒸汽、取芯后空位、修理台机芯和墙板变化。原图、对白、任务ID、奖励、战斗数值、地图碰撞、存档schema 15不变。

新增图片原件、生成说明和SHA256分别在`dist/assets/v30/`、[GENERATION.json](GENERATION.json)、[ASSET_MANIFEST.json](ASSET_MANIFEST.json)。按实测分区裁切图集，避免邻帧书架混入灯柱；守卫逐帧测量脚底锚点。

## 发现并处理的历史问题

- 原V29导航基线记录冷启动，V18在真实enter后移除退休筹牌桌，使第五章游艺厅可行走网格由590变598。保留原审计文件，另用干净基线代码采集真实进入后的118图导航对照，并单独断言该唯一非示范图差异。没有修改地图来凑测试。
- 早期连续试玩驱动遗漏后巷，并在跨图后继续寻旧坐标；修正驱动路径后重跑，未改游戏出口。失败记录见`qa/earlier-main-play-failure.json`。
- 原网页测试要求固定`0.28.1`，构建报告也写死旧版本/提交。本轮标题改为0.30，构建器从CURRENT_STATE读取版本，记录实际HEAD、dirty状态与输入内容哈希，测试核对当前版本。为了兼容旧下载/CI，离线文件名仍为`Ashen-V28.1-Play.html`，文件名不代表内容版本。旧失败见`qa/earlier-package-version-failure.json`。

## 仍然存在的限制

本轮是已落地的第一章表现改造，不等于整个游戏达到最终美术标准。地图拓扑和多数物件位置仍沿用原设计；建筑/树木轮廓仍有重复，室内布局与水岸形状还需逐场景深化。主角、动物及多数NPC保留原动作帧，尚未全部重画为独立多方向动画。没有重新设计主线对白、敌人AI或难度，也没有完整通关八章。

V29原任务及缺失的历史发行说明仍是独立未完成工作；原始开发历史与最新未发布source仍未找回。GitHub保存与网站部署分别记录；本轮没有发布原站或公共试玩网站。

python3 tools/build_web_play.py --output qa-export/v30-build
