## 问题与方向

1. 建筑、家具、任务物来自不同代图集，描边、透视、饱和度不同；方格路与重复树冠强化拼贴感。统一低饱和手绘环境图集，按物件功能映射，缩小地面纹理尺度、柔化道路边界，保留入口和足部碰撞。
2. 库房以四组书架充当货物，街道摊位孤立，物件缺少接地和使用痕迹。用货架/麻袋、车辙、落叶、门前磨损、灯光和水汽体现用途，装饰避开任务交互点，不新增隐形碰撞。
3. 操作环与常驻入口标签让场景像按钮集合。V29 interact 等待改为当次提交，保留距离、视线、任务前置、重复领取防线；附近才显示名称，取消圆环，用实物承载可交互信息。
4. 怪物程序绘制的骨脊、羽冠、披饰会浮在身体上。第一章使用原物种轮廓，去掉额外几何装饰，保留伤害预警。
5. 身体攻击、命中与倒地的运动衔接弱，大面积紫色特效遮住动作。补蓄势、出手、受击偏移、短暂倒地余像，收敛普通攻击特效；瞬态不进档、不改伤害/攻速/冷却/随机数。
6. 调查和修理结果不够可见。沿用原任务状态驱动画面：取物后空位、蒸汽释放、修理台机芯、墙板打开；剧情、奖励与旧档进度保持。
