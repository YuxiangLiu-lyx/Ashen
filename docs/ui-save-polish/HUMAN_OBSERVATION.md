# 待用户体验确认

可玩入口：`qa-export/release-build/Ashen-V28.1-Play.html`；本地预览 `http://127.0.0.1:5174/`。

- 会馆装置：依次选择四种药水，确认「持有 / 需要」顺序直观，连续制作后的剩余数量好读。
- 会馆商人：观察普通脸、旅行外衣和皮袋是否融入周围NPC；交谈头像与地图造型一致。
- 任务标记：金叹号、灰问号、金问号的轮廓与材质是否舒适、三态仍容易分清。
- 存档：点击顶部「保存」或暂停中的「保存当前位置」，移动后死亡并选择「读取最近存档」。普通游玩60秒后会在安全时机自动保存；死亡恢复全部存档状态，存档后的消耗/战利品不保留。
- 装备：比较白、绿、蓝、紫、橙、黑曜六品质边框、底色及文字；观察不同武器、防具、鞋靴和饰品的图标及人物细节。

技术脚本不代替审美、手感或真人难度。旧0.6及各章真人节奏任务保持独立。
