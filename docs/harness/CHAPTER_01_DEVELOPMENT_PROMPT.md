你是 Ashen《烬誓：圣女与影刃》的开发者。本轮任务是建立大重构的首章试点：**先把前两章剧情与长期设定记录完整，再实现第一章的地图场景、剧情和关键演出**。实现必须与本章记录一致，第二章先保持策划状态。

## 1. 先记录，再开发

按根 `AGENTS.md` 开工，保护现场、同步 main、读取 progress，建立独立任务和阶段。先分别运行 harness 查询“第一章剧情”“第二章剧情”“分卷分章”，读取：

- `docs/harness/NARRATIVE_WORKFLOW.md`：每章先写剧情、登记、记录采用稿版，再开发的流程。
- `docs/harness/NARRATIVE_ARCHITECTURE.md`：分卷分章结构和章节登记表。
- `docs/harness/CHAPTER_01.md`、`CHAPTER_02.md`：前两章完整稿，必须阅读全文，不能只读 router 摘录。

核对两章进入/结束状态、逐场对白、任务、地图、人物知识、揭露上限与相互承接是否完整；必要实施调整先改稿、再改代码。第一章记录采用版本，置 `DEV_FROZEN`；第二章保留 `SCRIPT_READY`，记录本轮不实装。冻结是执行记录，不要求重复向用户申请已经授予的开发权限。

`docs/harness/WORLD_VISION.md` 是可选长期参考。涉及阵营动机、长线伏笔时读对应部分即可，不要求每次读全文。其中用户确定方向须遵守，可改建议与未定事项保留开放；不自行定死血脉、预言、地狱性质或最终计划。章稿已包含本章必须知道的设定。

## 2. 本轮必须贯彻的人物与叙事

艾莉娅真诚善良、相信光明教廷，这有教育和亲身救济经历的根据。她会医治、保护旁人、判断危险和主动反抗。第一章经历刺杀，并不立刻接受被杀者的罪证或抛弃信仰，也不因为共同逃亡就原谅绑架者。

诺恩以任务为准则，少谈价值判断。他可以观察、判断路线和控制战术，却不能在开篇已经成为以救民为己任的侠客。此时保护圣女有明确的活体任务理由，后来的情感变化留出成长空间。

卡德兰的救济名声与实际侵害同属地方事实。第一章向玩家提供可追索的异常或局部证据；圣女未见同一证据，仍以自己的真实经历判断。责任落到具体行为者，不把光明教廷整个系统直接宣布为邪恶。血魔制造、外来配方、精华回收和二人最终身份都不在本章说明。

薇蕾娜知道第一次行动的主目的包含掳走圣女。她通过检查封术印、撤离路线和接应承诺表现专业与对诺恩的关心；她此时真相信接应存在。上级弃置和第二次开门替代手段留在第二章稿规定的范围揭露，第一章不做阴谋解说。

## 3. 第一章地图场景全面优化

先审计从灰烛会馆到灰石驿站、以及本章可选探索的真实地图与触发，提交本章地图清单和主/支路线图。不要把历史“11图表现范围”直接当作本章全部地图。

逐图落实空间功能、地标、光照、生活痕迹、交互、敌人读法、通路与剧情站位。会馆让玩家看到地下组织内部的日常和行动秩序；道路体现贸易、消息和城镇的联系；城镇与圣堂能看见真实救济、排队与不同群体；圣堂是有外部公共空间和内部私密空间的建筑；小巷/水渠有能理解的追捕及撤离路线；驿站提供有代价且有解释的短暂喘息。支线应支持探索和生活，紧急追捕阶段限制闲逛的原因必须成立。

用户授权第一章必要的布局、几何、物件和通路重设计。保留旧导航基线作对照；对确实改变的入口、碰撞和坐标逐项写理由、新验收及旧档迁移。保护未开发章节与有效支线状态。剧情图与俯视地图共用门窗、祭台、桌椅、伤者、站位和出口契约；美术先根据平面方案构图，不能一张图一个房间。

## 4. 关键剧情演出与可玩交接

按 `CHAPTER_01.md` 实现完整主线，重点落实：

**行动布置 → 圣女帮助民众的真实片段 → 刺杀 → 她不解并立刻救治 → 救治失败后的悲伤 → 保护旁人与阻止诺恩 → 双方主动交手 → 诺恩创造近身条件 → 封术印压制 → 圣女仍反抗并被带离 → 追捕与驿站 → 有限知情的幕后剪影。**

刺杀、相遇/救治和封印使用原创的强表现力剧情图与对白演出。参考《无期迷途》的美术完成度和关键叙事节奏，落到本游戏自己的暗色奇幻设计：

- 原创角色立绘及表情：圣女平静照护、惊愕、专注救治、克制愤怒、悲伤、决意；男主动作清楚、情绪克制；薇蕾娜有专业、亲近与戒备的变化。
- 关键图按空间契约设计：刺杀的关系与距离；沾血救治的手和目光；圣女挡住去路；术式与影刃冲突；封术印接触与光线熄灭；带离后的回望。审美重点放在面部、手、布料、光与构图，伤亡和受害证据呈现服务剧情。
- 分离背景、人物、前景、光效等层；有目的地切换全景、中景、特写，运用少量推近、位移、表情及姿态变化，保持可回读的对白记录。重要沉默、呼吸、钟声和术式断裂声与台词绑定，文字不要替画面重复解释。
- 图要承载具体情绪与事件，重要情绪不能只靠同一张立绘换台词。保持角色服装、伤势、道具、光向及空间连续；所有新资产记录本地字节、来源/生成说明、映射与哈希。借鉴表现方法，使用原创角色与画面。
- 关键段才开启专门演出，普通行走、支线与交互保留 RPG 节奏。对白可逐句推进、回看、跳过和降低动态；移动端/不同画幅不能裁掉手部封印、人物脸或文本。

圣女的主动交战按章稿做短的非致死剧情对抗：她有防御、限制行动和护人目标；玩家通过躲避、打断屏障/术式、逼近制造封印机会。把屏障或术式作为目标，不让玩家把她血条打空再复活。所有已有基础职业可完成；玩家失败可以重试；DOT、处决、词缀触发、召唤/同伴攻击都不能造成圣女死亡、掉落或刷奖励。普通地图若为安全区，也必须能进入本次明确授权的剧情战斗。全局平衡无需调整。

封术印只限制本章约定的主动圣术，不能变成思想控制。圣女保留移动、说话、拒绝与普通照护能力。固定刺杀镜头中的短刃属于剧情动作道具，不能永久替换玩家当前职业和装备。

幕后短场景保留老人、修长女性、好战年轻人的不同剪影与环境。脸不露，身份不报；每人依据不同的有限媒介或消息采取一步行动，不在同一个会议室全知讨论二人命运。不把“要变天了”扩成长篇预言解释。

## 5. 状态、兼容与验收

把场景进入、刺杀事实、交战进度、封印生效、逃脱完成分别记录；检查现有 `flags.assassination` 和章节 phase 的提前推进，不能以一个旧flag表示整段已完成。设计稳定场景/事件 ID 与提交点。逐句继续、整段跳过、回看、读档重入都只能提交一次；回看不发奖励、不改变角色知识。

核对现有最终对白覆盖层、StoryFlow/Cinematic、staging及 pending 迁移，不只修改底层 `DIALOGUES`。至少验证新档完整第一章、旧档刺杀前、救治中、交战中、封印后、逃亡中与已过章状态；跳过/重进不重复任务奖励、不强制重播给过章玩家、不错误解除封印。
