# 通用游戏设定

2026-10-13用户明确约定。本文件是地图、任务与引导开发的通用契约；新需求明确修改时更新版本与回归。第一章0.9为本轮实施范围，其他章节的作者剧情、布局与经济不因本文件自动重构。

- 任务由有明确缘由的NPC接取，执行后向对应人物报告/交付；支线不会自动替代主线追踪。新旅程默认主线，玩家可手动追踪支线或目的地，取消后回主线。
- NPC标记与对话选项共用语义：金色感叹号=可接取；灰色问号=已接但未完成；金色问号=现在可以交付，或主线已指向此人的可推进交接。找薇蕾娜时应是金问号。优先级为可交付/剧情交接、待接取、未完成；不允许金问号点开没有可执行的交接。物件不显示假任务标记，任务专用交互仅接取后开放。
- 地图可由多块可移动空间与走廊组成，并保留开阔图。用不同楼层、横向通道和回路丰富区域联系。地图目的地用文字方位、符合场景的门/台阶/路牌图片说明，不画指路几何装饰。
- 一个任务可分别要求多种怪物/材料，分布于不同地图或层。普通讨伐每类约7—10个，唯一精英单独记录；进度分项显示并指向尚缺目标。只有接取后的有效击杀/采集计入，刷新不清除进度，重复死亡事件不得重复计数/领奖。
- 普通常驻遭遇在每次真正进入地图时恢复该图配置的小怪和精英（有精英的图最多一只该精英），不受接取、完成或交付状态影响，不要求离场等计时。安全区仍安全，数量受地图固定遭遇上限约束。读取存档、ensureMap、同图重定位不算重入；剧情一次性人物和临时召唤体独立于常驻刷怪池，不能复活已结束的剧情。其他章节改造时也遵循此规则，并单独验收剧情边界。
- 门禁写具体世界原因：伤口、结构损坏、落闩、警戒、危险等；可自然提示相关人物。不能写“完成某任务/击杀某怪后进入”等系统条件清单。
- 掉落概率属于内部配置和开发证据，任务说明、对白、手记、提示不向玩家显示数字爆率或几成等概率。保留具体怪物、地点、材料、数量与用途。
- 物品形状、比例、位置及足部/碰撞应符合场景；墙板属于墙面，不能把独立栅栏放地上充当墙板。使用符合场景的原生图片，保留原件。

执行入口和回归见source/harness/modules.json的game_settings模块。标记、跨层目标、刷新、文本和迁移由tests/chapter-one-layer-rules.test.mjs验证；改动地图继续执行MAP_QUALITY的三项独立验收。
