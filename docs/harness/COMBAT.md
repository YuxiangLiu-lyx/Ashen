# 战斗与构建约束

数值真源：`stats` → growth 的属性/装备/章节修饰；`skillNumbers` → 职业/共通/地狱/进阶技能和刻印；`RPG.attack/skill/damage/hurt/update` → 真正结算；enemy-ai → V15 Boss scaling、防御、DOT、视线、AI 和弹丸。V17 输入队列是人类输入路径，直接 skill 仍有完整校验。

暗影 q 实际位移/命中并加两层流血；普攻加一层，血棘可能额外加层；上限四层，五秒刷新。e 在145距离内消耗流血，每层追加13原始伤害，再走真实伤害结算。血刃转职另用 careerBleed：上限30层、持续6秒、按基础战力/敏捷/力量结算；bloodHarvest消耗裂伤。不得把基础四层规则套到转职。Boss 对直接伤害和 DOT 有不同防御；不能只比较技能表的 damage 字段。V28 不增加第二个技能解释器。

V28 调整生成与旧档敌人生命比例、伤害倍率、经验/金币和独立1%额外掉落。实际 tier 使用玩家等级与敌人等级的最大值，三个等级一区间，19–22为第七层，23起第八层；不按章节。已有高等级玩家回旧图会进入高层池，这是既有边界，未经授权不得修掉或描述成章节限定。

刻印仅正值直接伤害触发；DOT/enchant/proc/反伤等不串联，冷却属于 actor.cd 而非装备对象。测试要覆盖递归、Boss、墙后目标、资源不足和原档 roundtrip。保留六类旧词条与装备 ID。装备和技能设计意图独立写入任务 decisions，候选数值不直接改正式规则。
