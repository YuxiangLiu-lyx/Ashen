# 《烬誓》长期世界观与叙事重构参考草案

版本 `WORLD-VISION-0.1`，2026-10-10；状态 `REFERENCE_DRAFT`。章节登记与采用记录见 [叙事架构](NARRATIVE_ARCHITECTURE.md)，具体开发遵循 [章节流程](NARRATIVE_WORKFLOW.md)。

**文档性质：策划参考，不是已实现内容，也不是完整定稿。**

本轮目标是为整个游戏的大重构提供共同的讨论基础。本文不介绍或承接现有后续章节，不要求开发者保留旧章的剧情结论。第一、二章以本轮用户描述为重构起点；之后的具体章节需逐步共同创作。

本文适合作为 harness 的**可选参考**：涉及世界观、角色长期成长、势力动机或信息揭露时，按需查阅相关部分即可；不必每次任务都读全文。它不替代当前任务指令、具体章节方案或仓库中的实际状态。采用某项建议后，应在正式设定与实现记录中明确标记，不得把草案自动当作既定事实。

## 一、用户确定的重要设定

### 1. 故事的规模与基本立场

游戏是宏大的奇幻 RPG 叙事，采用多卷、每卷多章的结构。诺恩与艾莉娅是核心视角，但世界并非只围绕二人运转。不同组织、群体和人物有自己的历史、利益、行动与命运。

每章应有足够的探索、人物、事件、冲突和行动。章节可以揭露一部分真相，也可以推动主线或角色关系；推进应由当下事件自然产生，不能把章节写成不断交接阴谋说明的流水线。

光明教廷、黑暗教廷都存在更宏大的计划。前期刺杀与地方罪行不是整个世界的全部矛盾；两教也不能简单对应“表面善良、实际邪恶”和“表面邪恶、实际善良”。两教须有真实职能、内部利益与分歧，而不只是给反派提供名称。

读书人的协会、商人协会、国家与君王，以及暂未出现的组织，必须实际影响世界的运行。它们不能只在幕后会议里出现，也不能只为解释一段主线而临时成立。

### 2. 艾莉娅的起点与成长

艾莉娅最初真诚相信光明教廷，认为它在帮助人们。她自己的教育、身份和生活经历支持这种信任。她非常体恤人民，不愿看见有人死，会主动尝试救人。

她之后会遇到超出眼前救援范围的问题：异族、自然侵害、内斗、资源与秩序等。她需要逐步认识到，单纯希望所有人获救并不能自动解决所有冲突。她会成长为愿意作出艰难决定、承担后果、能担起大梁的人。

这一成长包含逐渐能够接受部分人的牺牲，但不能被简化为“她终于不善良了”。她的责任能力与善良应共同成长。

### 3. 诺恩的起点与成长

诺恩最初缺少理解和表达感情的能力，以实现任务为主要准则。他并非天生具备成熟情感伦理的侠客，也不是没有判断力的傻子。

他会在共同经历中逐渐理解感情，开始害怕艾莉娅死亡，并作出超出命令的选择。二人的决定与关系发展会逐渐脱离部分布局者的掌控，也可能同时触及另一部分人曾尝试促成的结果。

成长必须有实际影响：他们会改变某些人的命运、计划的产物、势力的判断和后续局势，不能所有自主选择最后仍被一句“也在计划之中”取消。

### 4. 不平凡背景与预言的开放性

男女主可以有不平凡的背景，包括血脉、传承、体质、诅咒或预言身份，但具体答案尚未确定。

黑暗教廷促成两人的交集，与某种更长期的判断或预言线索有关。它不一定知道会发生什么；它可以尝试创造条件，而不能准确控制二人的感情和全部未来。

暂不锁定“谁是唯一圣子”“二人注定完成什么”“最终神祇与真正血统”等终局答案。

### 5. 前期光明教廷事件

前期两个刺杀对象是光明教廷体系中表面救济、实际上侵害妇女并掩盖罪行的人。女孩失踪与他们有关，部分罪行被嫁祸给黑暗教廷。

这些人不是掌握全部世界真相的关键人物。地方年轻一代或部分成员的堕落，不代表整个教廷从上到下都一致参与同样的罪行。上层有自己的困难与更大的事务，但这些困难不能抹掉具体成员及决策者的责任。

光明教廷内部存在设计杀害百姓、制造血魔的行动。这件事前期不直接向玩家揭露。中期可以逐步呈现其与更广泛危险、组织决策和利益的关系，但不能以“其实为了保护世界”替杀害无辜洗白。

血魔制造方法由另一个组织提供。该组织知道血魔会死，并预先安排了血魔死后精华的秘密回收。这条幕后利益链后期揭露。

### 6. 第一、二章的行动真相与薇蕾娜

第一次刺杀的重要目的，是制造掳走圣女的机会。薇蕾娜知道这部分安排。第二次刺杀同样用于促成诺恩与圣女的一段经历，而非仅仅为民除害。

黑暗教廷另有开门办法，却故意让诺恩认为必须带圣女完成这件事。相关疑点只能通过少量对话、安排和证据逐步显露。

薇蕾娜得到的承诺是有人接应。实际上，上级秘密安排两人进入“地狱”，并未告知她。她在与某人的交谈或核验中意识到自己被骗，因诺恩面临的危险而非常愤怒。

她与诺恩关系深，是关键角色。她参与了诱拐和隐瞒，因此并非完全无辜的旁观者；她反对上级背弃接应承诺，也不意味着她始终站在整个组织之外。

### 7. 关键剧情的表现方向

第一章的刺杀、艾莉娅的不解与愤怒、救治尝试、双方交战、封术印压制与掳走，应作为重点剧情演出。

可以借鉴《无期迷途》关键剧情的镜头、立绘表演、表情变化、声音与节奏组织方法，但使用本游戏自己的角色、画面、文字和资产。

幕后短场景可出现老人、身形修长的女性、好战年轻人等黑影形象。它们首先提供不同人物存在与世界开始变化的感觉，不应当场披露组织、身份和终极计划。

## 二、建议方案：供讨论、采用或修改

### 1. 用一个共同问题连接宏大叙事

建议以“谁有权替别人决定必须付出的代价”为长期问题。

两教、国家、学者与商人可以都声称在维护某种必要秩序，却对危险优先级、资源分配、保密、牺牲与责任有不同答案。男女主的成长不只是发现谁说了谎，还包括判断哪些困难真实存在、哪些困局被人为制造，以及有没有成本更低的解决办法。

这不必成为角色反复讲述的主题句。它应体现在救援、运输、治病、征税、防御和普通人的生活中。

### 2. 势力应怎样进入世界

| 势力类别 | 建议的真实职能 | 建议的内部冲突与利益 | 对玩法和事件的实际影响 |
|---|---|---|---|
| 光明教廷 | 医疗、收容、仪式、教育、部分地区的防御与灾害应对 | 基层救助者、秩序维护者、改革派、地方获利者，对资源与保密有不同看法 | 医药和避难点是否开放；哪些人被保护；仪式资源怎样使用；罪证能否被追查 |
| 黑暗教廷 | 可讨论隐秘传承、地下情报、被排斥群体的避难网络、处理公开机构不愿处理的问题 | 重视行动者性命的实务派；把人当传承材料的派系；借教义扩大自身控制者 | 任务与撤离资源；秘密通路；交易与庇护；主角是否能拒绝任务以及拒绝后的代价 |
| 读书人的协会 | 文献、翻译、测绘、法律、历史与术式研究 | 公开知识与限制危险知识的冲突；独立研究与资助者要求的冲突；不同学派竞争 | 地图、证据鉴定、旧档案、仪式解释；哪些说法可验证、哪些记录不可轻信 |
| 商人协会 | 粮食运输、信用、仓储、雇佣、跨境通道 | 维持长期交易秩序与趁危机获利的冲突；小商与大商、地方与跨境商的分歧 | 价格、供给、补给线、运输任务、债务与承诺；一项选择能真实改变地区生活 |
| 国家与君王 | 法律、军队、行政、税收、土地与对外关系 | 王权与地方；军队与财政；继承与改革；国家与教会权力边界 | 通行、征用、治安、战争、司法与公共资源；命令会受执行者和现实条件改变 |
| 尚未公开的组织 | 少量确实有效的古代知识、技术或历史线索 | 技术人员与决策者可能有不同目的，所知也未必相同 | 通过配方、交易、中间人、回收行动影响事件，而非随时显身解释一切 |

不必现在为每一类势力建立唯一总部和统一意志。地方分支、学派、契约、个人叛离可以使世界更真实，也给任务留下空间。

光明教廷的真实救助不否认其成员的罪行；黑暗教廷提供避难也不否认绑架与利用。不同职能和责任可以同时存在。

### 3. 血魔事件的三层秘密

建议建立一条可验证的信息阶梯，而不是一次反转把旧理解全部推翻。

| 层次 | 玩家能逐步确定什么 | 仍不应直接知道什么 | 揭露应依靠什么 |
|---|---|---|---|
| 第一层：眼前灾难 | 血魔确实危害人群；有人死亡、失踪或被转移；现场有不一致的痕迹，幸存者的说法也不完整 | 谁组织制造、完整配方、宏观目的、精华用途 | 环境、受害者、战斗后的变化、相互矛盾的局部记录 |
| 第二层：组织行动 | 某些教廷人员参与杀害百姓与制造血魔；行动不是孤立的私德问题；他们声称面对更广泛的危险 | 配方是谁提供；声称的必要性是否全部真实；精华被谁取得 | 可追索的命令与资源流、不同职位的证言、决策者的回应，以及主角自己的核验 |
| 第三层：另一条利益链 | 技术来自另一组织；它提前安排死后回收，真正需要的可能不是一个活着的血魔 | 最终用途、该组织全部结构、男女主与其计划的终极关系 | 前期留下的回收痕迹、工具或物证，与后来获得的技术及行动记录相互印证 |

第三层不能把第二层变成“光明教廷完全无辜，只是被骗”。教廷中作出杀人决定者仍须负责；技术组织也有自己的责任。

为避免幕后全知，可以让“血魔会死”来自配方的寿命、失稳条件或回收预案，而不是准确预见主角的每一招。二人提前结束灾难，可以改变死者数量、残留状态、回收时机或其他结果。该组织可能仍拿到了东西，却没有完全得到它想要的结果。

具体技术原理暂不锁定；这里只确立一个原则：它能控制部分条件，不代表它能控制所有结果。

### 4. 薇蕾娜的可持续角色线

建议让她是有实务能力的行动统筹者或教官，而不只是关心诺恩的女性角色。她能管理路线、情报、资源与撤离；熟悉诺恩的习惯，也参与过把他培养成执行者的过程。

她相信只要流程足够可靠，就能让组织目标与手下的性命同时得到保障。上级用签署的承诺、分部门权限或真实的接应编码骗她，使她第一次发现自身专业能力也会被用作掩护。

她的怒意应转化为行动：核验哪项承诺不存在，要求开备用路线，寻找资源，决定是否违抗。不要只给她一段摔杯子或骂人的过场。

后续她面对诺恩质问时，应承认自己知道的诱拐和同行设计。她需要争取重新建立信任，不能用“我不知道后半段”把前半段的责任全部抹掉。

她可以有自己的同伴、立场和损失，也可以与诺恩发生真正的路线分歧。她反抗上级，不必立即变成脱离所有组织的绝对正义者。

### 5. 两位主角怎样成长，才不会变成说教

艾莉娅的成长建议遵循：先尽力寻找不牺牲人的方案，再确认限制是否真实，最后作出有限决定、承担后果并追究制造困局者。她可以判断错误，也必须在新证据出现后修正。

“愿意牺牲”应是个别局面中的困难能力，而非新的人格口号。不能让一个自称懂世界的长者讲完边境死人、资源不足，她便立即承认虐害百姓是必要之恶。宏观信息应改变她对问题的理解，不能替代证据和判断。

诺恩的成长建议从行动开始：最初保护她有任务理由；后来对某个与任务无关的人作出额外举动；再后来明知损害任务，仍决定保护她或拒绝某项命令。感情先表现为备用路线、伤势检查、犹豫与回头，最后才有能力表达。

二人的亲密关系需要经历可靠承诺、冲突与修复。绑架、封术和刺杀是关系负债，不应因共同冒险便立即消失。艾莉娅应保持拒绝、谈条件和反击的能力；诺恩需要逐步尊重她的选择。

### 6. 让幕后者强大，但不全知

建议分别记录每个布局者的四项边界：它掌握什么信息；能控制什么资源；预期什么结果；在哪些条件变化时会失算。

同一事件可以被多方利用，不能因此默认多方共享全部情报。一方知道路线，另一方知道配方，第三方只看到仪器异常。组织内部同样有权限、误读、隐瞒和执行偏差。

封术印启动后的幕后场景，可采用有限感应：与圣女受任仪式有关的旧接口出现异常，或某类已有媒介呈现短暂变化。不同人物只得到不同读数，需要复核或派人调查。不能从一次感应直接得知诺恩的身份、现场全过程与未来。

具体媒介、印的来源、作用边界与世界术式体系尚待讨论；不得为一个悬念镜头临时发明万能感应。

### 7. 多卷、多章的架构原则

建议每卷完成一个独立成立的公共事件，并推进一段人物变化。卷末可以留下问题，但本卷不能只有开题，没有解决与后果。

每章至少明确：某些具体的人想要什么；主角当下要做什么；有哪些阻力；需要玩家做出什么行动；这一章改变了什么。章节不一定都要揭露幕后真相，也可以让玩家见到一个组织的真实职能、建立关系、经历选择的后果。

每卷至少有数种不同节奏：紧急行动、探索判断、人物相处、局部生活与高潮。支线可表现主线造成的影响，也可有自己的生活逻辑。不要让每个普通人都持有关键遗物或终极情报。

暂只给少量宏观方向，不指定后续章节：

- **相遇与共同经历的阶段**：从局部任务进入陌生处境，建立二人最初的冲突、依赖与有限信任。
- **公共责任扩大的一组卷**：观察不同群体与机构的实际需求，让个人救援逐步连接治理、资源、国家和边境。
- **历史与计划可被追索的一组卷**：通过已经留下的证据，逐步查明某些技术、组织与预言解释的来历，形成真正的立场分歧。
- **自主选择产生新秩序的阶段**：二人不只是逃离掌控，还要与其他人协作，实践有代价的替代方案，并面对其后果。

这些方向可以交错，每个阶段可以包含多卷。不要把“介绍一个新势力”当作每卷的机械主题，也不要提前锁定终局战役与结局。

## 三、暂未完善、需要逐步讨论的内容

| 待讨论事项 | 现在应保留的边界 | 定案时需要回答的问题 |
|---|---|---|
| 世界的地理、年代与历史 | 宏大感不能只依赖地图数量和远古名词 | 各地区为什么不同，交通与战争如何影响普通人的生活？ |
| 两教的起源、教义与真实公共职能 | 不先定为一正一邪，也不要求全部成员共享一个秘密 | 人们为何信任或依赖它们，各自内部哪些分歧可以公开存在？ |
| 学者与商人的组织形式 | 不先锁名字、总部和所有领袖 | 它们怎样获得资源、维护规则；何时与国家或教廷合作、何时发生冲突？ |
| 王权、国家、异族与自然侵害 | 外部危险可以真实，但不能成为无限免责理由 | 各方有哪些自己的需求和内部群体；被称为威胁者是否也有普通人？ |
| 男女主的特殊背景 | 暂不定血统、圣子身份、最终预言答案 | 哪些早期证据需要支持该答案，答案怎样保留自主选择与成长？ |
| 预言的性质 | 不以预言保证每一次剧情必然发生 | 它是解释、推算、传承记录还是另一种机制；为何有人相信，失败例子是什么？ |
| 封术印与圣女能力 | 有清楚的准备、作用范围、代价和解除条件 | 为什么此次能奏效，为什么不能无限封住任意强者，多方能感知什么？ |
| 第二次任务与门 | 黑暗教廷另有办法，诺恩未被告知 | 替代办法是什么，谁知道，为什么被保留，薇蕾娜究竟知道到哪一层？ |
| 接应骗局与进入地狱 | 薇蕾娜相信有接应，上级主动隐瞒 | 谁签署承诺，如何骗过专业核验，为什么值得冒这个风险，失败时谁损失什么？ |
| “地狱”的性质 | 先保留称呼，不直接定为神学地狱或古代实验场 | 里面是什么、与外界怎样连接、上级掌握哪些旧信息、哪些事实已经变化？ |
| 血魔的宏观目的与精华用途 | 责任链、外来配方与死后回收已确定；最终用途未定 | 杀人者为何作出决定，技术方想得到什么，两人的行动怎样改变结果？ |
| 薇蕾娜的外形、经历与组织位置 | 有独立能力、关系与责任，不只充当情感陪衬 | 她如何认识诺恩，有哪些既往选择，什么会让她真正改变立场？ |
| 黑影人物与新组织 | 先提供有限存在感，不能每位都成全知总导演 | 各自实际知道什么、能做什么；是否需要成为独立组织，还是已有体系中的个人？ |
| 总卷数、每卷章数与分支范围 | 长线结构为内容服务，不为填满数量而添加剧情 | 可承载多少玩法和演出，哪些选择改变路径，哪些变化必须跨卷持续记录？ |

定案顺序建议从第一章的人物行动、封术规则和信息边界开始，再完成第二章的任务、门与接应逻辑。远期背景只先留下可容纳多种答案的证据接口。每次讨论确认少量内容，再将其转入正式设定，避免一次性把整个世界锁死。

本草案的三类内容应始终分别记录：用户已明确的设定；经讨论后采用的方案；尚待讨论的空白。开发者不得用“自动补全世界观”替用户作出血脉、预言与最终真相的永久决定。
