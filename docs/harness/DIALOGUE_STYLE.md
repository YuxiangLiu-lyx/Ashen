# 中文对白风格规范

来源：用户2026-10-14叙事升级需求。此处是编辑原则，不给文学打分，不是运行剧情的新设定。配合 [纯风格参考](DIALOGUE_STYLE_SAMPLES.md) 与当前人物事件状态使用。

人物首先在与另一个人交流。他想问清事情、获得帮助、说明原因、拒绝要求、安慰或威胁，也可能只是同熟人闲聊。先确定这个目的，再决定说法。不要先想一句漂亮的台词，然后让人物替它找理由。

## 说清楚是默认，长短由事情决定

正常、完整、清楚的中文是默认。说明计划、争论责任或讲述经历时，可以连续说两三句，也可以在确有需要时说得更长。玩家应能理解行动的原因、争论的对象、计划的办法和改变主意的依据。不能为了少占几行，让玩家猜完整段因果。

“对不起……”“够了。”“我不知道。”可以成立：人物惊恐、羞愧、难以启齿、拒绝或确实无需解释时，都可能这样说。检查的是这次为什么说不下去，不是机械删除所有停顿。连续用“你……”“我知道”“可是”“别说了”替代重要交流，会把信息藏空；补回该交代的内容。

## 文学表现服从人物

允许庄重、优美、激烈、含蓄或华丽的表达，只要符合教育、身份、关系和当前目的。普通交谈可以平常地说，不必每场升华命运、光明、救赎，也不要求故意写得粗糙来显得真实。

留意反复出现的“不是……而是……”“真正的……从来不是……”，以及抽象总结、冷笑、反问、嘴硬、俏皮话和场末金句。这些不是禁词。遇到时问：人物为什么此刻需要这样说，对方会如何接话，是否真的传达了信息。不要让所有人都像训练有素的辩手。

用户指出的“先立下规矩，才能更好地……”需要同样判断。如果人物确实要安排一项工作，就交代谁需要遵守哪条要求、为什么、发生争议时怎么办；不能拿泛泛的规矩和价值宣言代替实际交代。若实际争论的就是制度原则，完整讨论也可以成立。

## 人物差异来自认识与关系

语言差异应来自关注点、措辞、理解能力、情绪表达、交流方式与知识背景。不能只给每人分配一个口头禅。一个人对熟人、陌生人、上级、敌人会有不同态度；这些差异也会因经历变化。

诺恩早期会观察、追问和解释任务判断，情感理解有限不等于没有正常交流能力。艾莉娅关心具体受伤的人，也能说明为什么反对某个决定；不必逢人发表生命演说。薇蕾娜可以亲昵逗趣，也能准确谈正事；不要把所有交流改成暧昧。以上方向仍要受当时的档案、事件和关系限制。

人物情绪必须有原因。先找他知道的事和刚经历的事，再写反应；不能因为作者需要张力便突然怒斥，因为需要亲密便突然调情，也不能用几句道歉抹掉绑架、背叛等关系负债。

## 编辑检查

### 否定祈使与劝阻模板专项（2026-10-14）

人物正常说话，不需要时时劝阻、教育别人或替别人总结人生。真正需要阻止某个行为时，再使用相应语气。

逐场识别“人物称呼＋别……”“别总……”“别再……”“别把……”“别让我……”，也检查承担相同功能的“不要”“不必”“无需”“不用”。关心、担忧、愤怒、亲昵和保护欲不能自动变成劝阻：想知道伤势就询问伤势，安排任务就解释事情，不满就说明原因；询问、观察、安排、商量、责备和直接表达意见都可以自然成立。

合理的否定祈使应保留。战斗中制止危险动作、发现即将发生的错误、明确拒绝、紧急警告或有身份依据的实际命令，完全可以说“别动！”“别碰那个！”。保留理由应指出当时的动作、危险或边界，而不是仅写“符合人设”。

重点检查一场内的连续重复，以及不同人物是否用同一种劝阻、关怀或说教方式说话。次数和句式统计只提示风险，不能直接判坏，更不能要求清零。先读完整场景，核对双方关系、各自行为目的、前后接话与真实情绪，再决定保留或修改。

修订不能只把“别”换成“不要”“不必”，不能丢失必要信息、切碎句子、增加省略号或强塞潜台词来降低频次。以完整的交流目的重写，保留合理的长短句与人物差异。

工具 `dialogue_style.py` 给出逐场候选、邻近重复与跨说话人分布；它过滤“特别”“别的”“要不要”等明显非祈使形式，剩余候选仍需语境判断。新审查稿声明 `style_policy_version: 2`，在 `editorial.negative_imperatives` 中记录场景目的及每条候选的保留/修订理由。专项结论不替代原七维编辑判断。运行修订另保存扫描分布、原句/修订句对照和正常用语保留例。

逐场读完整对话，再检查七个方面：人物是否一致；语言是否自然；信息与因果是否清楚；时空与任务是否连续；玩家和人物的消息是否隔离；伏笔是否越过揭露上限；情绪与关系变化是否有依据。给出具体位置和建议，保留有理由的长句、短句和特殊语气，不用字数、关键词计数或总分裁定质量。

游戏适配同样必要：长对白可以分页，不可破坏 pending 行号、演出动作、说话者与一次性提交。新增行数须检查存档迁移与实际对话框；不要因为技术上的旧行数方便，就删掉必要解释。此次 Harness 升级不自动改动任何现有对白。
