# 每次地图变更的三个独立验收维度

适用地图布局、碰撞、路径、NPC岗位、场景渲染和人物资源修改，包括小改动。读取受影响地图及其调用者；保留改前证据。三项均须单独完成，任何失败或未知均不能用其他项抵消。自动脚本只检查几何事实和证据完整性，不声称能自动判断审美。

1. **可玩性 playability**：实际RPG blocked/clearLine/moveActor生成可达/不可达/碰撞/瓶颈图；走通每个入口到出口与任务目标，检查真实实体不穿透、NPC不堵路。相关野外检查近战、远程、追击、脱战、绕障、技能、范围攻击躲避和多敌；普通区240×192仅为24像素脚部直径的初始参考，不以面积比例代替实战。
2. **场景可信度 scene_credibility**：实际游戏分辨率全图及局部对照，说明地理、道路/建筑用途、物件为什么在此、主次与留白、NPC岗位/停顿/活动依据。禁止随机堆物作为主要布局逻辑；每种地图保留自己的结构节奏。
3. **角色一致性 character_consistency**：实际人物截图与原画/角色映射对照，分别检查相似性、职业轮廓、头身比、服装、脚锚、前后遮挡及待机/移动/攻击。士兵/精锐/军官依赖独立设计，不依赖同图缩放或换色。缺资源记录未完成，不接受占位图冒充。

## 持久证据及门禁

用 `task.py run` 记录真实检查。验收写到 `docs/map-quality/LATEST.json`：source_fingerprint、reviewed_paths（相对路径）、assets（path/sha256）、maps数组。每图id下三个维度各自包含 status=pass/failed/unverified、reason、evidence数组（每项path/sha256）。必须实际查看图片和报告后写理由，不能仅根据文件存在批量自动批准。未执行的检查注明限制与复现步骤，维度保持unverified。

`python3 tools/harness/map_quality.py --base <任务基线>` 验证当前源码、改动覆盖和证据哈希；task.py finish 对真实地图/美术改动自动调用该校验，即使未手动声明必需检查也不能绕过。check.py --recommend 自动推荐三维检查。代码、资源或证据改变后需重新检查相关维度并更新记录。历史回执不覆盖，LATEST只是当前证据索引。
