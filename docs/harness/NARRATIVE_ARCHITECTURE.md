# 长期叙事架构与章节登记

版本 `REBUILD-NARRATIVE-0.3`，2026-10-10。长期采用多卷多章；当前按用户回滚后的要求，仅第一章局部增强，运行版仍为 V30。前两章记录以稳定版主线为底稿，不因架构规模重写已满意的任务对白；不介绍或改写旧后续章节。

## 整体结构

采用“多卷 → 每卷若干章 → 每章若干可玩事件与关键演出”。卷围绕一个有阶段结局的核心冲突组织，章节承担具体事件、一个能落地的新认识以及人物关系变化。卷数和每卷章数尚不固定；可先以每卷 4–6 章作为容量估算，不能为凑数拆散事件或跳过生活与探索。

首卷暂名 **《圣城之外》**：以两次任务和一次被隐瞒的弃置为入口，使一名只会执行命令的影刃与相信光明教廷的圣女共同离开熟悉秩序。首卷最终解决的问题、后续章数仍待创作；第一章负责相遇与强制绑架，第二章负责有意制造的同行经历和接应背叛。

后续卷只保留宏观设计槽位：城市公共秩序与战争成本；知识和商路对统治的影响；边境与不同族群的生活；历史记录、传承和预言的可靠性；主角取得决策权后的代价。这是可以重排的方向，**没有锁定卷名、终局或逐章情节**。细节按后续章节策划逐步确定，参考 [长期世界观](WORLD_VISION.md)。

## 每章的内容要求

- 有能在本章推进或结束的地方事件，不能只提供下一段阴谋的线索。
- 主线、人物事件、探索/战斗与生活支线相互支持。旁支能让玩家认识不同群体、资源争夺或制度后果，同时保留不直接服务阴谋的日常。
- 真相揭露分辨“发生了什么”“谁做的”“为什么做”“谁利用了结果”。一章不必全答；证据来源可追溯，玩家与角色知道的内容分别记录。
- 情感通过共同经历积累。圣女的责任成长并非逐章变冷酷，男主的情感成长并非突然发表长篇感悟。
- 关键剧情才切换强表现力演出；路上对话和普通互动仍保留 RPG 节奏。玩家行动改变具体代价、证据或关系，不能全部被幕后人声称早已算准。
