# V28.1 · 美工 / 表现修复

基线提交：`6a4371c5c870f7900a77d7d3c35b1d638ba1d9b8`。本次是既有游戏上的增量修复，不是重建游戏，也不改写 V28 战斗数值。

## 已实现

### 碰撞、遮挡与比例

`presentation-physics-v281.js` 补充没有 authored box 的树干、墙体、建筑基座、门柱、水盆、床和推车；门框保持中间通行。大型敌人移动/寻路使用更大脚底半径，包括已有桌椅的足部轮廓；直线寻路与移动共用同一间距。无名运行时家具获得独立稳定 ID，入座时不会批量忽略其它对象。卡位修复包含当前同行，不挪动倒地者或搬运中的患者。原有细网格剧情寻路、坐席切换和患者搬运例外保留。入图/读档时才修复卡在障碍里的角色，常规移动不以瞬移替代寻路。

排序仍以脚底为准，增加显式 footY 支持；树冠和屋檐的遮挡采样按角色实际高度计算。诺恩84、艾莉娅80、澄璃81、一般 NPC82 world px；小型动物和 Boss 使用分开的比例，不以同一倍率放大。

### 步态、怪物与 Boss

补齐伙伴/通用 NPC 的实际行走距离，避免怪物步距被重复累计。主角、圣女、澄璃、守卫、动物和地狱敌人继续使用现有真实多帧姿态。缺少循环帧的后备 NPC 只对下肢进行四相交替接触处理，头部不整体晃动；这不是新增完整手绘行走图。

取消 V28 按玩家等级强行改变怪物物种的渲染替换。狼保持狼，鼠保持鼠；战斗类型、HP、伤害及任务判断不变。首领使用已有的独立金属伏行者、熔炉重甲、骑士、灵体、处刑者图集；守日者使用重甲而非玛尔塔的女性外观。披肩、裂旗、日轮、判书、骨脊等结构装饰区分身份，不以纯色相偏移作为唯一差异。

### 武器、装备和透明边缘

诺恩不再整体跳过头/胸/鞋的显示；采用贴合现有帧的头、手、脚锚点细节，保留人物脸和原服饰。24 件 V28 稀有装备都有外观签名，部分共用同一造型家族；不是24套全新身体图。灰牙磨刃的齿刃、焦骨刻刃的骨脊缠带、断誓余烬刃的焰纹、烬誓的蚀环刃饰分别使用不同结构。主副武器维持职业类型，双手武器仅在支持手位置合理时修正角度，避免翻转穿身；修复只持副手时品质丢失。

5 张女主、澄璃、生活姿态及 Boss 图集经过透明底与边缘色溢清理，尺寸和帧坐标不变，原图不覆盖。`ASSET_MANIFEST.json` 保存来源与输出校验值，`tools/build_presentation_assets.py` 可重建。

### 第八章演出

第八章大图从活动图集注册、演出节拍、预加载和 HTML 展示四层禁用。原有对白、小立绘、任务链、场景内站位演出保留，其它章节的大图不受影响。历史 CG 留在原归档以便追溯。
