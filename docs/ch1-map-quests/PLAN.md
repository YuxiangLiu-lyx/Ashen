- 库房：三片堆货区环绕宽十字货道；六鼠与一处墙缝；灯油改鼠群掉落。
- 旧王道：宽东西道路、北林地支路、南车辙空地相连；阿林与损车同场景，资源在草地。

- 水渠：双岸＋两桥＋东闸宽战斗区，追缉官必须击败才能离城。
- 溪边林地：入口草甸、上游药圃、东岸兽窝三片空地由浅渡/桥相连；溪水延伸到边界。
- 客房：卧榻、炉灶与桌角，连贯安静房间，无多余取水任务物。
- 磨坊小径：屋前院、轮槽、后场三块连通；狼衔铜圈，机房入口有台阶。
- 回声机房：入口间、检修廊与守兽巢；击败守兽取得机芯，机械属于机械。
- 修理铺：开放工作间，柜台/工具/练习角各就其位。
- 练武庭：围栏三片实战场地，有苔壳爬兽；击杀目标替代技能靶/预警靶点击。
