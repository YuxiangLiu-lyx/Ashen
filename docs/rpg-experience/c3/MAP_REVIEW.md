# 第三章地图三维审阅

执行编辑已查看14张正式全图、两洞窟改前后画面、碰撞叠图、原有NPC与敌人16帧画廊。实际渲染在current-maps-final，改前在baseline-maps-complete。新增几何只有苔窟与矿道；其余12图保留原有空间。以下是编辑判断，真人找路、审美与操作手感仍待验。

可玩性：14图共182条入口到交互接近点，用正式blocked、clearLine与moveActor实际移动验证。两个重整洞窟的全部可达网格分别330/330、326/326，原出口、任务与生成物ID保留。此处移除敌人仅为测路；战斗另外用正常UI、真实入图群战和Boss实验验证，不能用网格面积替代。

场景可信度：新的两洞窟通过房间、通道和资源用途组织；不再把整张开敞地面称为洞道。岩边缘使用原chapterHell素材，视觉与碰撞边界同源；重复岩形仍可见，轨道仍是原有Canvas画法，本轮没有新增原画或宣称达到用户未提供的两张参考图效果。其他12图沿用既有构图，宽阔场地与少量重复石堆属于明确保留项。

角色一致性：医生、工匠、船夫、教习机看守沿用原hellNPC图集与对白立绘；艾莉娅救援时使用原独立圣女职业/技能，诺恩恢复后回到原职业和个人行装。猎犬的骨架轮廓、亡魂兜帽、守卫铁甲红布及典狱长的肩甲锁链与原16帧一致，脚锚和运动姿态沿用正式渲染。既有精英标签/颜色不被称作新增独立种族。本轮未替换这些人物或敌人资源。
