# 五部门版本包 · 使用方法

这次把文案剧情与地图探索独立开来。五部门当前资料已经分别整理成V0.zip；你以后只需把对应部门新版本文件放到对应目录，再让本地Codex读取最新版本。

## 先把项目放到Mac

下载ashen-vow-v9-studio.zip并解压，得到ashen-vow文件夹。若旧项目已有本地修改，解压到新位置，让Codex比较，不直接覆盖。

建议放到文稿/Projects/ashen-vow。安装Node.js 24 LTS后，打开终端：

```sh
cd ~/Documents/Projects/ashen-vow
npm ci
npm run dev
```

浏览器打开http://127.0.0.1:4173/。也可以让本地Codex处理启动。游戏源码在dist；整个项目文件夹一起交给Codex。本包未在你的Mac实机运行。

## 给五个GPT会话的东西

每个会话粘贴对应启动提示词，并上传该部门V0.zip。包中是现有资料；目前没有安排新设计，具体要求由你以后补充。V0是交接版本号，和游戏自身V9无关。

| 部门 | 当前基稿与后续版本目录 | 启动提示词 |
| --- | --- | --- |
| 文案剧情 | departments/narrative/V0.zip | studio/prompts/01_NARRATIVE.md |
| 地图探索 | departments/maps/V0.zip | studio/prompts/02_MAPS.md |
| 美术 | departments/art/V0.zip | studio/prompts/03_ART.md |
| 系统体验 | departments/ux/V0.zip | studio/prompts/04_UX.md |
| 战斗 | departments/combat/V0.zip | studio/prompts/05_COMBAT.md |

文案包包含实际最终对白、逐人物对白索引、角色/剧情/伏笔原档与演出记录。地图包包含合成后的当前地图、出入口、NPC与交互点、隐藏链、刷新及奖励参考。美术包提供真实原图、图片索引、当前切片锚点、现有画风与截图。系统和战斗包各自提供对应现状、数据和实现依据。

地图部门负责隐藏事件的设计和触发，文案部门维护其中正式文字与人物表现；不要让两个部门分别改写一套角色剧情全文。

## 每次只交一个版本文件

例如文案部门依次交V1.zip、V2.zip，放在departments/narrative/。美术部门依次交V1.zip、V2.zip，放在departments/art/。其他部门相同。每个ZIP根目录是README.md，其余所有文字、数据和实际图片放在包内。

**每个新版本必须完整包含本部门仍有效的全部材料。** V2保留V1未改的内容；不能只交“修改了第几行”，也不能把旧图省略成“沿用上次”。这样Codex只读一个最新版就足够。若要移除旧内容，在本版说明中明确写出。无需batch_id、delivery.json或多份交接表。

编号各自独立，五个部门不必齐步到同一版本。Codex按最大数字选择，所以V10比V9新。只接受V数字.zip这样的名称，下载时出现的V2 (1).zip需要改回正式编号；不要用修改时间决定最新稿。不要覆盖旧版本，修订时增加编号。

## 给本地Codex的总prompt

打开根目录CODEX_PROMPT.md，复制全文发送即可。内容只包含读取位置、最新版选择和代码整合工作，不再列角色、技能、地图或具体玩法要求。

也可直接发送：

> 请执行根目录CODEX_PROMPT.md，读取五个部门的最新版本并按我本轮要求完成实现。

Codex会运行npm run studio:latest，把五个最新包解压到studio/current，再依据latest.json中的路径读取。这个目录是自动生成的，不在这里编辑设计；新设计始终作为新的ZIP放在departments对应目录。

如果五个部门还都是V0且没有新任务，Codex只接手，不擅自重做游戏。以后只要相关部门有新版本，你告诉Codex本轮要实现什么；未变化的部门继续使用原最大编号版本。

各GPT聊天不会自动写入你的Mac，你只负责下载和放文件；本地Codex负责读取和实现。无需把整段聊天反复复制给主程，也不必先上传GitHub。

## 独立测试

可继续保留第二个Codex测试会话，使用studio/prompts/07_CODEX_QA.md。由主程准备固定版本副本，测试报告回到qa/reports。测试prompt同样只读取材料与实现记录，不重新写游戏设定。

旧的四部门/inbox/batch交接方式已从当前工作入口移除。历史经营和游戏记录仍保留；后续设计以你给的最新版部门包为准。
