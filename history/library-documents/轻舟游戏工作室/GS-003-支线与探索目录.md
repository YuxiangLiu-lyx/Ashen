## 2. 已实现的普通 NPC 支线

### CH1-S01：别把灯油倒了

- 发起人：灰烛会馆的管家奥伦 `steward`。通过“那半罐灯油还要吗？”等角色话语提出，不使用“领取下一份任务”作为对白。
- 路线：会馆东门 → 旧库房；入门后往西北侧看，灯油容器在 (390,290)。拿到后从库房西门返回，交给会馆中部偏北的奥伦。
- 物件：`oil`，显示为灯油容器。虽然旧数据类型叫 `crate`，它有专门的互动动作与油罐图案，不能当普通木箱攻击破坏。
- 状态：未接 → 接受对白结束后 `active`；持有 `oil` 至少 1 → 可交付；交付对白结束消耗 1 份灯油 → `done`。
- 奖励：30 经验、15 金、疗伤药 ×2。没有装备或技能书。
- 顺序与重复：可以在接任务前先找到灯油；接取后仍能正常交付。物件 `used` 与任务 `done` 分别阻止重复拾取和重复结算。
- 人物作用：补足奥伦对粮食、灯油、泥鞋和会馆生活的关心，让开场驻地有可回去的人与事。

### CH1-S02：少了一封信

- 发起人：旧王道西段、道路北侧的信使阿林 `courier`，现有位置 (430,400)。
- 路线：从阿林身边沿王道往东，转弯处南侧有翻倒邮袋 (1000,650)。附近可能有狼。拿到未投递的信，再沿原路往西回阿林处。
- 物件：`letter` / 翻倒的邮袋。保留封口完整的信，不提供拆信探知教廷秘密的选项。
- 状态：未接 → `active`；持有信 → 可交；交付消耗信 → `done`。
- 奖励：40 经验、20 金、《疾行》×1。玩家需在行囊主动阅读书，再自行放入快捷栏；拿到即自动学会或自动替换技能不符合当前规则。
- 顺序与重复：可先捡到信再询问阿林；已经交付后不会凭聊天再得书。
- 人物作用：阿林关心把信送到收信人手里。刺杀后与首章完成后有新的送信见闻，但不因一句“今天还往城里送？”再生成任务收益。

### CH1-S03：三株银叶草

- 发起人：白榆城药摊的米拉 `herbalist`。
- 常规采集路线：白榆城西门 → 旧王道；可找到三株，分别在北侧 (650,290)、东南路边 (1090,800)、东北路边 (1270,320)。另有溪边旧径西南侧 (400,700) 的一株，不要求解锁隐藏地图才可完成这项普通支线。
- 物件：`herb1`、`herb2`、`herb3`、`groveherb`；每个节点当前只采一次，每个给银叶草 ×1。不是可反复刷新、无限收集的药田。
- 两条交付路径共用一个任务状态。都要求先接米拉的任务，且持有至少 3 株。

| 交给谁 | 选择的情境 | 结算 | 后续影响 |
|---|---|---|---|
| 米拉 | 交给药师配药 | 消耗 3 草；45 经验、20 金、疗伤药 ×3 | 记录 `herbChoice=mira` |
| 蕾娜 `woman` | 她弟弟发烧，先将草药送过去，药钱记在米拉账上 | 消耗 3 草；45 经验、20 金、研习札记 ×1 | 记录 `herbChoice=woman`、`oldLead=true`；她提醒去问井边婆婆 |

- 选择后任务为 `done`，不能另交 3 株把另一条奖励也领一遍。没有选中的分支不再开放该任务奖励。
- 蕾娜给的是父亲留下的练剑笔记，以 `pointBook` 实现，使用后 +1 技能点，并非新主动技能。
- `oldLead` 是人物推荐与衔接提示。它不直接打开北面隐藏路，也不是银环线唯一前置；没有帮助蕾娜的玩家仍可自己聊天发现旧桥。
- 给居民送药不自动增长圣女好感；圣女对杀人和挟持的判断不会被一份药抵消。

### CH1-S04：晚归的路

- 发起人：针线铺附近的朵莉 `dolly`。她因为失踪传闻担心收摊后的归路，不只是为了给玩家一项任务而站着。
- 步骤：答应替她核实 → 去白榆城北面的门卫托马处问清楚 → 回到针线铺附近转述。
- 未核实就让她早点回去，会被追问。没有惩罚或永久失败，但不能直接领奖。
- 核实内容保存为 `lanternRoute=before/after`，当前实际阶段取 `chapter < 3 ? before : after`。

| 世界阶段 | 托马给出的可走路线 | 提交规则 |
|---|---|---|
| 刺杀前 | 从井边向北，沿礼拜厅门前的灯走；门卫守到天黑 | `before` 才有效 |
| 刺杀后 | 礼拜厅方向封路；从井边向西绕药铺，与收摊的人同行 | `after` 才有效 |

- 如果问完路后先去刺杀，再返回答复，旧路线会过期；需要再问一次托马。不能把玩家未核实的过时消息当成功。
- 奖励：35 经验、稀有护手“缝补过的护腕” `quest-lantern-hands`，攻击 +1、生命 +8、无词缀。无金币。奖励进入行囊，手动装备。
- 任务状态与固定物品 ID 双重保护，一份存档中不重复发。即便装备行囊已满，这件唯一任务奖励也保留，不折成零钱。
- 她收起部分摊位物件、调整收摊安排，是已经帮上忙的具体反馈。尚未做完整 NPC 出城寻路，因此不得描述为玩家已护送她安全到家。
- 首章正式离城后只能加载离城前快照回顾，不代表失踪案解决、通缉撤销或现实回城。

## 3. 已实现的隐藏线：修钟人的旧物

这条链不是怪物或 Boss 战利品。入口是人说的话与旧物痕迹，终点是一段家人的回忆和一件有来历的遗物。

1. 在白榆城与“修钟人的妹妹” `oldwoman` 聊旧桥，第一次只知道她在找人问路。
2. 两条线索入口等价：继续聊第二次；或者第一次聊天后，查看广场井沿的名字，再问“井沿刻的是谁的名字？”。
3. 听完旧桥线索后设置 `rumor=true`。旧王道北面的溪边旧径入口显现。
4. 从白榆城西门回旧王道，在北侧岔口 (920,190) 进入溪边旧径；从该图南口往东北探索，第三块松石在 (1250,320)。普通狼可以打掉，也可试着绕开。
5. 调查松石，找到银环与工钱纸，设置 `silverFound=true`；物件标记已查找。工钱纸和暂存的旧银环目前用剧情状态表示，不在普通背包分别添加两件可交易材料。
6. 原路从旧径南口回王道，再向东回白榆城。把旧物给婆婆，她留下哥哥的纸，把银环交给维兰。

固定回报：史诗遗物“修钟人的银环”，攻击 +3、生命 +12、逐雷词缀 `storm`。当前逐雷会让闪避伤害到附近敌人；这个词缀本身也可能出现在普通装备上，不能宣传为独占技能。没有额外经验或金币。

完成时 `silverReturned=true`，清除 `silverFound`，直接把银环放入装备行囊；重复对话不能再发奖。当前生成的银环实例 ID 仍由装备工厂创建，唯一性靠任务标志，和朵莉护腕的固定 ID 方式不同。

这条隐藏链使用 `oldTalk`、`wellSeen`、`rumor`、`silverFound`、`silverReturned` 等状态，当前没有独立 `QUESTS` 条目。线索与地图入口已经实现，但若任务手记尚未单独显示它，不应声称它有完整独立追踪 UI。后续添加隐藏任务手记时应由首次明确线索触发，不能新建存档就把答案列给玩家。

## 5. 旧练习环与三张可进入地图

已批准方向是“更多能进的房间和岔路，有少量值得发现的战力选择”。原有客房、修理铺、小径三图继续保留。V7另外增加机房、洛缇和可选精英，不增加主线前置。

| 地图 ID | 入口和返回方向 | 互动内容 | 战力收益 |
|---|---|---|---|
| `guestroom` 会馆客房 | 从会馆北门进；南门返回会馆 | 床、行程簿、清水盆、火炉；可休息 | 恢复当前 HP/MP，除此无永久收益 |
| `workshop` 白榆修理铺 | 进白榆城东北屋门；南门回城 | 修理工作台、工具架、可攻击木桩、旧件说明、取件纸牌 | 旧练习环的开端与组装点 |
| `millpath` 旧磨坊小径 | 旧王道南岔口进入；北口返回 | 西墙油布包、旧练习痕迹、磨盘、断轮轴、桶罐 | 固定暴砍练习页；铜圈任务进度；普通怪和桶罐的常规掉落 |

### 三步链和自然入口

任务 ID 统一用 `copper`，任务名“旧练习环”。

1. **读修理台便条。** 台上是铁指环，外圈铜线卸下重磨；便条直说铜圈在旧磨坊西墙边的包裹里。没有神秘预言。修理铺木牌先说明台边旧件可由街坊自取，工具用后归位，避免任务在叙事上变成偷盗。
2. **到磨坊取回铜圈和练习页。** 从修理铺南门回城，走城西口到王道，沿南岔路进旧磨坊小径。西墙低墙旁 (430,560) 的油布包内有铜圈和《暴砍练习页》。一次取回。铜圈仅以 `practiceCopper` 等任务标志保存，不占常规物品栏，不再建立一套材料收集栏。
3. **回工作台装好旧环。** 小径北口回王道，向东进城，再进东北修理铺。根据便条扣好铜圈，结算“缠铜练武环”与 30 经验。没有金币、第二件装备或锻造等级。

可以先逛到磨坊拿包裹，再去修理铺补齐线索并完成组装。不能要求玩家把已经发现的包裹放回去、再按“正确顺序”重拿。

| 固定内容 | 规则 |
|---|---|
| `cleaveBook`《暴砍练习页》 | 油布包最多补给一份；若已持有或已读过同种书则不再加第二份；任何初始职业都可学，公式以力量为主。阅读不要求空激活位；全部可学，同时最多激活5种主动战技 |
| `quest-copper-practice-ring` 缠铜练武环 | 稀有遗物；攻击 +0、生命 +8；持法杖时暴砍与断魂击 ×1.35，法术及法杖普攻 ×0.8；其他职业只得生命收益 |
| 30 经验 | 组装完成时结算一次，取包裹不提前再发同一任务经验 |

铜环展示的是“力量成长和手动力量加点的法师，借武器与特殊装备尝试近战”的明确取舍。正常精神加点法师虽然能读战士技能页，威力并不会自动等于力量战士。环不让法师同时获得无代价的近战与法术优势。

### 防重复与边界

- 同一油布包拥有领取标志，铜圈与技能页只加一次。读取、关闭、读档、重复点击都不得多发。
- 最终组装重新核验持有铜圈与未完成条件；先将任务转为完成，再处理独特装备和经验。完成后只显示工具已归位、工作台已收拾的文字。
- 当前铜环采用满包延后领取：行囊满 60 格时保留铜圈进度，不扣材料、不标完成、不发经验，提示腾一格再收起练武环；腾位后可重试。不会自动折价；不自动穿戴，不覆盖现有遗物。这与旧护腕直接保留在满包行囊的处理不同。
- 已知技能、已持有书、激活位已满的处理应由同一学习系统控制；不能额外生成一套“探索书学习方式”。
- 修理铺 (740,460) 有独立可攻击训练木桩，不倒地、不掉物、不发经验；磨坊的旧练习台保留可读练习笔记。两处均没有第二次领书条件，不反复授予力量或经验。
- 旧铜环工作台只处理这件定好的旧物；另一张炼洗台有两种有限重置配方，详见新增内容。不开放采矿循环、熔炼、无尽锻造、抽词条和锻造等级。
- 书柜、锁柜上的锁不意味着每个都能开出稀有物。别人的寄存物以环境文字说明不动，不生成一串泛滥的钥匙。

### 关联人物与文本

托马曾经学过一点法术，后来改练近身。他承认旧修理单是自己的，能解释练习页上的歪字和赔过的木杖。刺杀后他忙着疏通救护车辆，回答会短些；不从一件旧环突然变成法师导师或隐藏 Boss。

修钟人的妹妹只知道修理师傅临时外出、工具应放回去；V7由女儿洛缇看铺；不兼任本章万能工匠，也不与哥哥银环那条故事强行合并。

圣女若在安全区同行，可在客房明确表示站在门边等；在修理铺提醒不能乱拿别人的物件。看到“旧件可自取”的木牌后，她只核对边界，不因此理解男主或增加恋爱好感。新闲聊延续第一章敌意。
