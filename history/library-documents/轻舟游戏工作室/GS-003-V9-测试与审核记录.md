# V9 浏览器实测记录

日期：2026-09-10。测试目标为本地受管预览的最终 V9，非线上旧版。总制作人操作真实浏览器；独立测试员负责程序回归。截图在同目录 `screenshots/`。

## 方法与边界

浏览器当前视口为 1363×936。另以同源测试容器使游戏获得精确的 1366×768、1920×1080 CSS 视口，读取游戏 DOM 尺寸确认；容器按显示器空间等比缩小，因此截图不是两个物理显示器的原生尺寸。容器已从发布目录移除，测试来源保留于 `tests/fixtures/qa-layout-v9.html`。

章节、物品和战斗定位使用真实 RPG 格式测试存档，从游戏公开的“导入存档”界面粘贴导入，随后通过实际按钮、鼠标和键盘操作。没有用浏览器私有变量直接改进度。定位存档不等于自然通关。

## 实测发现并修复

1. 1366×768 技能页页签受弹性布局挤压：固定面板标题及页签的收缩行为，两尺寸复验。
2. 圣女普通对白中存档后恢复，仅有立绘而无场景角色：保存同行者位置/可见性/朝向，恢复对白时安排面对面站立。旧档缺少同行者字段时使用附近合法落点。新增 `tests/v9-dialogue-companion-resume.mjs` 检查当前档与 V8 回退。

另有独立测试定位的首次受击报错、墙边同伴归队和隐藏入口被墙挡住，已经修复并复跑对应检查；详细证据见 `QA_CHECKLIST.md`。

## 尚未验证

没有声称三职业都由真人完整自然通关两章；没有实测新内容将自然游玩时长提高30%～50%。数值模拟用确定性策略与开放场地，不等同普通玩家操作。未完成真实手机、长时间性能、Steam/手机安装包验收。四帧动画及素材融合仍有继续打磨空间。

## 复现

`npm test` 运行当前 V9 系统、剧情/秘密、物理路线、对白同行者恢复和战斗规则检查。`npm run test:v9:balance` 单独生成三职业确定性战斗模拟；不要将模拟时长写成自然通关时长。旧版检查保留为 `test:legacy` / `test:v8`。

### 总制作人整合后补验

浏览器已完成两种精确 CSS 视口的布局与交互检查，采用当前物理浏览器内等比显示的1366×768及1920×1080测试容器，详见 `v9/BROWSER_QA.md`。修复技能页页签被压窄、圣女普通对白存档恢复后场景角色消失；当前档及V8档恢复专项检查通过。取消转场后主动重试与运河Boss所有常规出口锁定亦通过。系统16项、剧情4项、物理路线143项在整合后复跑通过。

- 独立 QA 部门不修改 Site，不操作浏览器；将复现脚本与报告交总制作人整合。

- 未观测的层级/美术问题不能标为“已复现”；未实际试玩的体验不能标为“已满意”。
