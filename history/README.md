# 历史原始文档

`library-documents/` 是已恢复原始交付中的 `.md`、`.txt`、`.json` 原文镜像，保留原相对路径和字节，便于浏览。这里包括历史版本、旧索引与旧发布记录，不代表当前开发版本。当前权威状态请读取仓库根目录说明及 `source/README.md` 指向的文件。

其他原件连同这些文档一起保存在 `archives/library-originals.tar.gz.part*` 中；每卷与原文件的校验信息见 `archives/library-originals.manifest.json`。损坏的原始 ZIP 仍保留原字节，并在 manifest 标记，不代表它本身可以解压。
